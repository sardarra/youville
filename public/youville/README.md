# Youville artwork

Original SVG artwork exported from Figma in `Youville Design.zip`.
The town component uses the complete buildings and decorations instead of the
individual image fragments referenced by the Anima code. Original filenames are
preserved, including `Fountaion.svg` (the fountain spray).

The heading and company label remain live text so the app can personalize them.
Additional exported SVGs are retained for future use.
